# 🧩 Puzzle Game (8-Puzzle)

An interactive **8-Puzzle sliding game** built using **HTML, CSS, and Vanilla JavaScript**.  
The goal is to arrange the tiles in the correct order by sliding them into the empty space using the **minimum number of moves**.

---

## 🎮 Game Features

- 🔀 **Randomized board** on every refresh
- 🧠 **Logic-based tile movement** (only adjacent tiles can move)
- 📊 **Move counter**
- 🏆 **Win detection system**
- ⭐ **Star rating based on performance**
- 🔄 **Restart / Refresh button**
- 🎨 **Image-based tiles for a visually appealing puzzle**
- 🖥️ Fully **responsive layout**

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the game
- **CSS3** – Styling, grid layout, animations
- **JavaScript (Vanilla)** – Game logic, randomization, win detection
